月次家計簿（独立動作版）
==========================

■ これは何か
iPhoneのブラウザで動く家計簿アプリです。サーバーも会員登録も不要で、記録は端末の中だけに保存されます。
レシートの文字認識も端末の中で行います（画像は保存も送信もしません）。

■ 使い始めるには（置き場所が必要です）
iPhoneのSafariは、パソコン上のファイルをそのまま開いてもデータを保存できません。
このフォルダ全体を「https の静的ウェブサイト」として置き、そのURLをSafariで開いてください。
置き場所の例（いずれも無料枠あり。画面の手順は各サービスの案内に従ってください）:
  - GitHub Pages
  - Cloudflare Pages
  - Netlify
置くのは index.html を含むフォルダの中身すべてです（vendor フォルダも必須。約22MB）。

■ iPhoneへの追加
1. SafariでそのURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はホーム画面のアイコンから起動する
※ Safariのまま使うと、しばらく開かない間に記録が消えることがあります。必ずホーム画面に追加してください。

■ 大事な注意
- 記録は「URLごと」に別々に保存されます。置き場所のURLを変えると、記録は引き継がれません。
  URLを変えるときは、先に「設定 → バックアップを書き出す」で保存し、新しいURLで「バックアップから復元する」を使ってください。
- バックアップは月1回を目安に取り、「ファイル」アプリやiCloud Driveに保存してください。
- 初めてレシートを読み取るときだけ、日本語データ（約14MB）の読み込みで少し時間がかかります。2回目以降はオフラインでも読み取れます。

■ MoneyForwardの記録を取り込む
1. MoneyForward MEのWeb版で、家計簿画面の月を選び、下の「ダウンロード」でCSVを保存（プレミアム会員のみ）
2. このアプリの「設定 → MoneyForwardのCSVを取り込む」で複数の月をまとめて選ぶ
3. 分類の割り当てを確認して「取り込む」
取り込み直後は「取り消す」で戻せます。同じCSVを再度取り込んでも、重複は自動で除かれます。

■ レシートの品名を正確に残したいとき（文字を貼り付けて取り込む）
「レシート」ボタン →「文字を貼り付けて取り込む」。
 A. iPhoneの文字認識：写真アプリでレシートを開き、文字認識マークから文字を選択してコピー → 貼り付け
 B. Claudeに読ませる：画面の「Claude用の依頼文をコピー」を使い、Claudeアプリにレシート写真と一緒に送る → 返ってきた文字を貼り付け（複数枚は一度に貼れます）
カード名・電子マネー名（JCB、QUICPayなど）は、レシートの表記として表示され、支払方法に追加できます。

■ レシートを読み取る（写真から・端末内）
1. 「レシート」ボタン → 撮影、または写真を選ぶ
2. 確認画面で、日付・店名・支払方法・各行の品名/金額/分類を確認して直す
3. 分類が未選択の行がある間は登録できません。「候補」と出ている行は自動で付けた分類なので、確認してください
4. 「登録する」で明細が1行ずつ記録されます（「合計1件で登録」も選べます）
明るい場所で、レシートを濃い色の面（机・かばん等）に置き、真上から撮ると読み取りやすくなります（背景から紙の部分を自動で切り出し、傾きも直します）。
小さい文字の品名は読み間違えることがあります。確認画面で直してください。

■ 毎月の支払い（自動で記録）
支出の入力画面にある「毎月支払う」にチェックを入れて保存すると、毎月の同じ日に、同じ金額・カテゴリ・支払方法・メモで自動で記録されます。
- アプリを開いたときに、支払日が来ている月の分を記録します（しばらく開かなかった場合は、まとめて追加します）
- 31日払いなど、その月にない日は月末の日付になります
- 金額を変えたいときは、最新の月の記録を編集して保存します（次の月からその金額になります）
- 支払いが終わったら、いちばん新しい月の記録を開いて「毎月支払う」のチェックを外して保存します。これ以降は記録されません（記録済みの月は残ります）
  チェックを入れ直して保存すると、再開します
- 自動で記録した月を削除すると、その月は作り直されません（その月だけ飛ばしたいとき）
- 自動で記録した直後は「取り消す」で戻せます
- 一覧の「毎月」の印で、毎月の支払いを見分けられます

■ 現資産（預貯金・株式・暗号資産を夫婦別に管理）
下のメニュー「現資産」で、いまの資産を項目ごとに入力できます。
- 種類：預貯金・現金／株式／ビットコイン／イーサリアム／ポイント
- 持ち主：夫・妻・共有（必ず選びます）。「すべて／夫／妻」で絞り込めます
- 預貯金の口座名は一覧から選びます。一覧にない銀行などは「＋ その他（自由入力）」で追加でき、次回から一覧に出ます
- 株式は、銘柄・保有株数・1株の価格（手入力）から評価額を計算します
- ポイントは、楽天ポイント・Vポイント・PayPayポイント・dポイント・WAONポイントから選び、残高（pt）を入力します。一覧にないものは「＋ その他（自由入力）」で追加できます。1ポイント＝1円として合計に含めます
- ビットコイン・イーサリアムは、保有数量と、取得した円建ての価格から評価額を計算します
  価格は「現資産」を開いたときと「価格を更新」で、インターネットから取得します（取得するのは価格だけで、保有数量などは送りません）
  取得できないときは前回の価格で表示し、資産の編集画面で価格を手入力することもできます
- 合計・持ち主別・種類別の金額と、項目ごとの割合を表示します
- 収入・支出の記録とは別のデータで、家計簿の収支には影響しません
- バックアップに含まれます（古いバックアップから復元しても、入力済みの資産は消えません）
- スプレッドシート連携の対象ではありません（この端末の中だけに保存されます）

■ Googleスプレッドシートとの同期（任意）
端末の記録が本体で、スプレッドシートは自動の控えです。シートで直した内容も取り込めます。
手順は gas/手順書.txt を見てください（GASコードは gas/Code.gs）。
- 合言葉(KEY)とURLは端末の中だけに保存され、バックアップには含まれません。
- 記録のデータをGitHubに置いてはいけません（アプリのファイルだけを置きます）。
