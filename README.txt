月次家計簿（独立動作版）
==========================

■ これは何か
iPhoneのブラウザで動く家計簿アプリです。サーバーも会員登録も不要で、記録は端末の中だけに保存されます。
レシートの文字認識も端末の中で行います（画像は保存も送信もしません）。

■ 使い始めるには（置き場所が必要です）
iPhoneのSafariは、パソコン上のファイルをそのまま開いてもデータを保存できません。
このフォルダ全体を「https の静的ウェブサイト」として置き、そのURLをSafariで開いてください。
置き場所の例（いずれも無料枠あり。画面の手順は各サービスの案内に従ってください）:
  - GitHub Pages
  - Cloudflare Pages
  - Netlify
置くのは index.html を含むフォルダの中身すべてです（vendor フォルダも必須。約22MB）。

■ iPhoneへの追加
1. SafariでそのURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はホーム画面のアイコンから起動する
※ Safariのまま使うと、しばらく開かない間に記録が消えることがあります。必ずホーム画面に追加してください。

■ 大事な注意
- 記録は「URLごと」に別々に保存されます。置き場所のURLを変えると、記録は引き継がれません。
  URLを変えるときは、先に「設定 → バックアップを書き出す」で保存し、新しいURLで「バックアップから復元する」を使ってください。
- バックアップは月1回を目安に取り、「ファイル」アプリやiCloud Driveに保存してください。
- 初めてレシートを読み取るときだけ、日本語データ（約14MB）の読み込みで少し時間がかかります。2回目以降はオフラインでも読み取れます。

■ MoneyForwardの記録を取り込む
1. MoneyForward MEのWeb版で、家計簿画面の月を選び、下の「ダウンロード」でCSVを保存（プレミアム会員のみ）
2. このアプリの「設定 → MoneyForwardのCSVを取り込む」で複数の月をまとめて選ぶ
3. 分類の割り当てを確認して「取り込む」
取り込み直後は「取り消す」で戻せます。同じCSVを再度取り込んでも、重複は自動で除かれます。

■ レシートを読み取る
1. 「レシート」ボタン → 撮影、または写真を選ぶ
2. 確認画面で、日付・店名・支払方法・各行の品名/金額/分類を確認して直す
3. 分類が未選択の行がある間は登録できません。「候補」と出ている行は自動で付けた分類なので、確認してください
4. 「登録する」で明細が1行ずつ記録されます（「合計1件で登録」も選べます）
明るい場所で、レシート全体が画面いっぱいに入るように撮ると、読み取りやすくなります。

■ Googleスプレッドシートとの同期（任意）
端末の記録が本体で、スプレッドシートは自動の控えです。シートで直した内容も取り込めます。
手順は gas/手順書.txt を見てください（GASコードは gas/Code.gs）。
- 合言葉(KEY)とURLは端末の中だけに保存され、バックアップには含まれません。
- 記録のデータをGitHubに置いてはいけません（アプリのファイルだけを置きます）。
